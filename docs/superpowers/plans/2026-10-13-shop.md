# Ship Shop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Players earn credits (🪙) from each game and spend them on purely visual items. The items are sabotage, defence, gifts, bling and emotes. Everyone in the room sees them, the shop's stock changes every game, and the host can switch the shop off per room.

**Architecture:**
- **Catalogue:** `shop.js` holds the item catalogue, the earnings formula and the random "today's market" roll. It is pure and tested.
- **Wallets:** `wallets-store.js` keeps wallets in memory, keyed by a hash of the player token. It changes them synchronously and saves them to `wallets.json` in the background.
- **Server:** `server.js` adds four new actions (`buy`, `wear`, `emote`, `settings`) and a `room.effects` list. It applies the limits and blocking rules, pays out credits at the game's end, and sends effects, bling, the market and the viewer's own wallet in each room view.
- **Client:** `index.html` adds the shop sheet, the on/off toggle, toasts, and drawings of every effect on the target's ships.

**Tech Stack:** Node 20+ built-ins only. The client is plain HTML/CSS/JS with SVG. Tests are plain Node scripts run by `npm test`.

**Spec:** `docs/superpowers/specs/2026-10-12-shop-design.md`

## Global Constraints

- Items are purely visual: they never change bids, bananas, payments, winners, scores, the harbour log or game history.
- Zero runtime dependencies; Node 20+ built-ins only.
- Credits per game: `floor(finalBananas / 10)`, +10 to each winner, +3 to every player when `room.torpedo`. Only players in `room.order` earn; spectators get nothing.
- Wallets live in `wallets.json` in `DATA_DIR`, keyed by `sha256(token)` hex. Raw tokens are never written.
- Prices:
  - Sabotage: bomb 12, kraken 15, cloud 8, shark 6, gulls 10.
  - Defence: hose 6, umbrella 4, bubble 10.
  - Bling: gold 120, rainbow 60, disco 80, parrot 40.
  - Gifts: bouquet 8, lei 5, bottle 3, cake 12, teddy 10, giftbox 15, fireworks 20, diamond 50.
  - Emotes: `honk`, `ha`, `oops`, `ouch`, free with a 10 s cooldown.
- Today's market: 3 sabotage, 2 defence, 4 gift and 2 bling items, rolled on room create and on every new game. Emotes are always available.
- Limits:
  - Sabotage: 1 per buyer per round, at most 2 active on one target, only while playing, only at a player in the game other than yourself.
  - Gifts: 1 per sender per round (round 0 in the lobby or on the end screen), any room status, never blocked, at most 3 shown per ship.
- Blocking: hose blocks bomb, umbrella blocks cloud, bubble blocks anything. The exact match is used first, then bubble. The attacker still pays.
- Lifetimes:
  - Sabotage and gift effects end when their round resolves. The diamond lasts until a new game.
  - Emotes and blocked effects drop from the view after 4 s. Round-0 gifts drop after 30 s.
  - `newGame` (start or rematch) and `lobby` clear all effects.
- Shop off (`room.shop === false`): every shop action answers "The shop is off in this room.", the view carries no effects and no bling, credits are still earned, and the setting carries into a rematch.
- Wallet storage unavailable: shop actions answer "The shop is closed right now.". Games, scores and history are unaffected.
- Error copy, verbatim:
  - "Not enough 🪙: Kraken costs 15."
  - "You've already sabotaged this round."
  - "Bo's ship can't take any more right now."
  - "Pick a rival's ship."
  - "Unknown item."
  - "Not for sale this game: check back next game!"
  - "You've already sent a gift this round."
  - "Wait a moment before the next one."
- Mobile-first: works at 320px, tap targets at least 44px, light and dark mode, reduced motion shows still badges, all names escaped.
- **Commits:** the user's CLAUDE.md requires their okay before committing. Ask once before Task 1 whether per-task local commits are fine. Never push or deploy without asking; pushing `main` deploys.

## Review Focus

1. **A rematch or new game after a sabotage round:** no effect from the previous game lingers on any ship. *(Task 5 test.)*
2. **Two players buying the last allowed sabotage on the same target at once:** the second is refused and keeps their credits, because actions run synchronously. *(Task 5 test.)*
3. **A room restored from an older `rooms.json` without `shop`, `market` or `effects`:** it works with the shop on and a freshly rolled market. *(Task 3 test.)*
4. **A player who rejoins (reconnects) still wears their bling, and their wallet is unchanged.** *(Task 5 test.)*
5. **Effects aimed at or sent by a player who has left:** dropped from the view rather than drawn on a missing ship. *(Task 3 test.)*

```js
  cake: { kind: 'gift', name: 'Cake', icon: '🍰', price: 12 },
  teddy: { kind: 'gift', name: 'Teddy bear', icon: '🧸', price: 10 },
  giftbox: { kind: 'gift', name: 'Gift box', icon: '🎁', price: 15 },
  fireworks: { kind: 'gift', name: 'Fireworks', icon: '🎆', price: 20 },
  diamond: { kind: 'gift', name: 'Diamond', icon: '💎', price: 50 },
};
const EMOTES = ['honk', 'ha', 'oops', 'ouch'];
const MARKET_SIZES = { sabotage: 3, defence: 2, gift: 4, bling: 2 };

// Today's market: a random pick per kind (partial Fisher-Yates with the given random, so tests can pin it).
function rollMarket(random) {
  const out = [];
  for (const [kind, n] of Object.entries(MARKET_SIZES)) {
    const pool = Object.keys(CATALOG).filter(k => CATALOG[k].kind === kind);
    for (let i = 0; i < n; i++) {
      const j = i + Math.floor(random() * (pool.length - i));
      [pool[i], pool[j]] = [pool[j], pool[i]];
      out.push(pool[i]);
    }
  }
  return out;
}

const earnings = ({ score, won, torpedo }) => Math.floor(Math.max(0, score) / 10) + (won ? 10 : 0) + (torpedo ? 3 : 0);

// The defence a target's stock spends on this sabotage: the exact counter first, then a bubble shield.
function blockerFor(kind, stock) {
  const exact = Object.keys(CATALOG).find(k => CATALOG[k].blocks === kind);
  if (exact && stock[exact] > 0) return exact;
  return stock.bubble > 0 ? 'bubble' : null;
}

module.exports = { CATALOG, EMOTES, MARKET_SIZES, rollMarket, earnings, blockerFor };
```

- [ ] **Step 3: Implement `wallets-store.js`**

```js
// Credits and shop items per device, keyed by a hash of the player token (raw tokens are never stored).
// Wallets live in memory so game actions can check and spend synchronously; saves happen in the background.
const crypto = require('crypto');
const { createJsonFileStore } = require('./json-file-store');
const { CATALOG } = require('./shop');

const FILE = 'wallets.json';
const idOf = token => crypto.createHash('sha256').update(String(token)).digest('hex');
const empty = () => ({ credits: 0, stock: {}, owned: [], worn: [] });
const copy = w => ({ credits: w.credits, stock: { ...w.stock }, owned: [...w.owned], worn: [...w.worn] });

function clean(r) {
  if (!r || typeof r !== 'object' || !/^[a-f0-9]{64}$/.test(r.id) || !Number.isSafeInteger(r.credits) || r.credits < 0) return null;
  const known = (k, kind) => CATALOG[k] && CATALOG[k].kind === kind;
  const stock = {};
  for (const [k, n] of Object.entries(r.stock || {})) if (known(k, 'defence') && Number.isSafeInteger(n) && n > 0) stock[k] = n;
  const owned = (Array.isArray(r.owned) ? r.owned : []).filter(k => known(k, 'bling'));
  const worn = (Array.isArray(r.worn) ? r.worn : []).filter(k => owned.includes(k));
  return { id: r.id, credits: r.credits, stock, owned: [...new Set(owned)], worn: [...new Set(worn)] };
}

function createWalletsStore({ dataDir = process.env.DATA_DIR || '/data', logger = console } = {}) {
  const base = createJsonFileStore({ dataDir, file: FILE, label: 'wallets', clean, logger,
    unavailableMessage: 'Wallet storage is unavailable.' });
  const wallets = new Map();
  const ready = base.ready.then(() => { for (const r of base.rows()) wallets.set(r.id, copy(r)); });
  let timer = null;
  const flush = async () => {
    clearTimeout(timer); timer = null;
    await ready;
    if (!base.available) return;
    await base.update(() => [...wallets].map(([id, w]) => ({ id, ...copy(w) }))).catch(e => logger.error('[wallets] save failed:', e.message));
  };
  return {
    get available() { return base.available; },
    logger, ready, flush,
    get: token => copy(wallets.get(idOf(token)) || empty()),
    change(token, fn) {
      const id = idOf(token);
      const w = wallets.get(id) || empty();
      fn(w);
      wallets.set(id, w);
      if (!timer) timer = setTimeout(flush, 250);
      return copy(w);
    },
  };
}

module.exports = { createWalletsStore };
```
